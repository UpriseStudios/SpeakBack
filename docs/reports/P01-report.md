Both builds: package `com.uprisestudios.speakback`, version 0.1.0 (code 1), `minSdkVersion 26`, `targetSdkVersion 36`, `native-code arm64-v8a`. The dev APK is `application-debuggable`.

There's no `RECORD_AUDIO` yet. Unity adds it automatically once `Microphone` is referenced; that's P04's job to confirm.

**INTERNET finding.** With "Internet Access" set to Auto (`ForceInternetPermission: 0`), the first release build still requested INTERNET. Unity's feature scan (`Library/Bee/artifacts/Android/Features/*-FeaturesChecked.txt`) flags `UnityEngine.Networking` in **Unity.InputSystem** and **Unity.RenderPipelines.Core.Runtime**. Both are required packages, so Auto will always add it. The fix:
1. `InternetPermissionStripper` (an `IPostGenerateGradleAndroidProject` hook) deletes the permission from the generated `unityLibrary` manifest for non-development builds. It also adds a `tools:node="remove"` marker so a future AAR can't add it back.
2. `BuildAndroidRelease` reads the finished APK with `aapt2` and **fails the build** if INTERNET is present.

This confirms P00 finding B8, and goes further: Auto adds INTERNET to release builds too, not only dev ones.

## Decisions taken in this session
- **TMP essentials committed rather than imported.** `AssetDatabase.ImportPackage` is asynchronous in batchmode, so the first font-asset step hit a null `TMP_Settings`. I extracted `TMP Essential Resources.unitypackage` from `com.unity.ugui` with a throwaway script and committed the result. `SceneBuilder` now fails with a clear message if those files are missing.
- **EmojiOne sprites removed** from TMP essentials. Their attribution file says to "review their licensing terms", which isn't confirmed against D-018, and they'd ship from `Resources/`.
- **HDRP TMP shader graphs removed.** HDRP isn't installed.
- **Scenes and font assets are generated by `SceneBuilder`** (menu: SpeakBack/Rebuild Scenes), so the skeleton can be reproduced and reviewed. Later prompts will edit `03_Game` normally, so re-running the menu item after P08/P09 would overwrite their work. Treat it as a bootstrap tool from P02 on.
- **Variable fonts.** Unity uses each variable TTF's default weight (400). Display weights for P09 will need static instances, as noted in dependency-decisions.
- **LFS for PNGs.** I kept the existing rule that puts every PNG under `Assets/_SpeakBack/Art/` in LFS, rather than carving out small UI icons. One rule is easier to get right, and LFS costs little for small files.
- **Q8 data sync not started.** No runtime JSON is read yet; P04 owns it, as agreed.
- **`SPEAKBACK_DEV` is not in the project's defines.** It comes only from `BuildAndroidDev` via `extraScriptingDefines`, and `Verify()` fails a build if it's ever added to the project defines. As a result, the Dev assembly doesn't compile in the editor by default (it's empty today). P04 needs a way to work on Dev code in the editor, for example a menu toggle that adds the define locally.
- **Template's `Assets/Settings/InputSystem_Actions` kept.** It's registered as the project-wide input actions asset, and removing it would only make the Input System recreate it.
